### Task logging

[[Capture Sample/Start|Choose language]]

1. Enable Obsidian’s core Daily notes plugin and configure its folder, date format and template. To isolate this example, use Capture Sample/daily, YYYY-MM-DD and Capture Sample/en/templates/Task Daily. Existing Daily notes settings can also be kept.
2. Enable Task completion log in Capture. Set its heading to ## Notes, matching the template.
3. Check the task below, then run Open today’s daily note. Find its text, source link and time under Notes.
