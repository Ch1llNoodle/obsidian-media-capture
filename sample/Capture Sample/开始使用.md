### Capture 示例库

先完成一条媒体记录，再按需要打开追踪示例。把整个 Capture Sample 文件夹复制到笔记库根目录，名称保持不变。

#### 第一次采集

1. 安装并启用 Media Capture，打开设置中的“开始使用”。
2. 点击侧栏的采集图标，粘贴小宇宙、Apple Podcasts 单集、豆瓣播客、YouTube 或 Bilibili 完整视频链接。
3. 获取媒体信息，确认标题、状态、日期和窗口下方的保存路径，选择“保存并打开”。

默认播客写入 Podcasts.md，视频写入 Videos.md；以插件当前设置为准。媒体采集无需 API Key，也无需 Dataview。网页信息获取失败时可以手填标题，封面失败仍可保存。

#### 显示操作控件

阅读、剧集、地点、学习、运动和豆瓣示例需要 Dataview：在 Obsidian“设置 → 第三方插件 → 浏览”安装并启用 Dataview；进入其设置，打开 Enable JavaScript Queries（启用 JavaScript 查询），然后切换到阅读视图。

页面提示开启模块时，到 Media Capture 的“功能”页开启模块，再重新打开示例页。需要服务的模块，在“服务连接”中填写对应凭证。只开启本次要试的功能。

示例脚本在 scripts/demo.js，随整个文件夹复制即可，无需改代码。追踪示例把记录保存在本文件夹的 data、daily、places 和 image 中，日期按上海时区归属。媒体和任务记录使用插件及核心日记设置中的位置。

不需要预先创建 data 文件；首次保存或同步时自动创建。打开示例不会请求远端服务或写入数据。手写摘抄放在豆瓣同步标记区域之外。
