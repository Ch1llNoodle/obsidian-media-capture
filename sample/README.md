### Capture sample

浏览器打开 GitHub 仓库，选择 Code → Download ZIP，解压后进入 sample 目录；也可使用已有源码。

把此目录下的 **Capture Sample** 整个文件夹复制到 Obsidian 笔记库根目录，然后打开 **Capture Sample/开始使用.md**。文件夹名称及 scripts 子目录保持原样。

媒体采集本身只需 Media Capture，任务示例还需 Obsidian 核心日记；互动追踪页还需要 Dataview 并开启 JavaScript 查询，日记来源模板需要 Templater。各页面列出了模块、凭证、操作步骤和结果位置。没有内置个人配置或凭证。

示例页面目前使用中文控件。阅读与肌群选择可离线使用；联网来源仅在点击按钮或运行日记模板时请求。

Copy the entire **Capture Sample** folder into the root of an Obsidian vault, keep its name, and open **Capture Sample/开始使用.md**. The sample labels are in Chinese. Interactive trackers require Dataview with JavaScript queries enabled; Daily source templates require Templater. Enable the relevant Capture modules and enter credentials in Service connections. Reading and muscle selections work offline. External requests run only after an explicit action.

Tracking data stays under Capture Sample; media and task logging follow your existing plugin and core Daily notes settings. Opening the examples does not import settings, request services, or create data.
