### Capture Sample

[简体中文](Capture%20Sample/zh-CN/开始使用.md) · [English](Capture%20Sample/Start.md) · [Français](Capture%20Sample/fr/Demarrer.md)

#### 简体中文

下载仓库 ZIP 后，将 sample 中的整个 **Capture Sample** 文件夹复制到笔记库根目录，打开 **Start.md** 选择语言。保留目录名称、scripts 和 assets；运动示例的人体图已包含在内。

追踪页面需要 Dataview 并开启 JavaScript Queries，日记来源模板使用 Templater，任务记录使用核心日记。各页面列明需要开启的 Capture 模块和服务凭证。

示例数据保存在 Capture Sample 内，媒体采集和任务记录沿用已有设置。日期使用 Asia/Shanghai，切换语言共用追踪数据。

#### English

Download the repository ZIP, copy the entire **Capture Sample** folder from sample to your vault root, and open **Start.md** to choose a language. Keep the folder name, scripts and assets; the Exercise body maps are included.

Interactive trackers require Dataview with JavaScript Queries enabled. Daily source templates use Templater; task logging uses core Daily notes. Each page lists its Capture module and credentials.

Sample data stays under Capture Sample; media capture and task logging use your existing settings. Dates use Asia/Shanghai, and tracking data is shared across languages.

#### Français

Téléchargez le ZIP du dépôt, copiez tout le dossier **Capture Sample** depuis sample à la racine du coffre et ouvrez **Start.md** pour choisir une langue. Conservez le nom du dossier, scripts et assets ; les schémas corporels de l’exemple Sport sont inclus.

Les suivis interactifs nécessitent Dataview et ses requêtes JavaScript. Les modèles quotidiens utilisent Templater ; le journal des tâches utilise les notes quotidiennes principales. Chaque page précise le module Capture et les identifiants nécessaires.

Les données exemples restent dans Capture Sample ; médias et tâches suivent vos paramètres existants. Les dates utilisent Asia/Shanghai et les données sont partagées entre les langues.
