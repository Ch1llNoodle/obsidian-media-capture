### Capture sample

[简体中文](Capture%20Sample/开始使用.md) · [English](Capture%20Sample/en/Start.md) · [Français](Capture%20Sample/fr/Demarrer.md)

把 **Capture Sample** 整个文件夹复制到 Obsidian 笔记库根目录，打开 **Capture Sample/Start.md** 选择语言。保留全部脚本、strings.json 与目录名称。中文、英文、法文各有完整的操作页面、按钮、提示和模板；书名、视频标识、肌群标识与数据路径在语言之间保持一致。

下载：在 GitHub 源码页选择 Code → Download ZIP，解压后进入 sample。阅读、剧集、地点、学习、运动和豆瓣页面需要 Dataview 并开启 JavaScript Queries；日记来源模板需要 Templater；任务示例需要核心日记。媒体采集本身无需这些插件，也无需 API Key。

Copy the entire **Capture Sample** folder to your Obsidian vault root and open **Capture Sample/Start.md** to select a language. Keep scripts, strings.json and folder names. English, Chinese and French include complete pages, controls, messages and templates. Stable record identifiers and paths are shared across languages.

Download the repository with Code → Download ZIP, then open sample. Interactive trackers require Dataview with JavaScript Queries enabled; Daily source templates use Templater and task logging uses core Daily notes. Media capture itself needs none of these extra plugins or credentials.

Copiez tout le dossier **Capture Sample** à la racine du coffre et ouvrez **Capture Sample/Start.md** pour choisir une langue. Conservez scripts, strings.json et les noms des dossiers. Les pages, contrôles, messages et modèles sont disponibles en français, anglais et chinois ; les identifiants et chemins des données sont communs.

Téléchargez le dépôt avec Code → Download ZIP, puis ouvrez sample. Les suivis interactifs nécessitent Dataview et ses requêtes JavaScript ; les modèles quotidiens utilisent Templater et les tâches les notes quotidiennes principales. La capture de médias ne nécessite aucun de ces ajouts.

Tracking data stays under Capture Sample. Media capture and task logging use your existing settings. Examples contain no credentials and make no external requests on opening; requests begin only after clicking an action or inserting a Daily source template. Dates use Asia/Shanghai. Provider content and backend errors retain their source language.
