### Capture sample

[简体中文](Capture%20Sample/zh-CN/开始使用.md) · [English](Capture%20Sample/Start.md) · [Français](Capture%20Sample/fr/Demarrer.md)

把 **Capture Sample** 整个文件夹复制到 Obsidian 笔记库根目录，打开 **Capture Sample/Start.md** 选择语言。保留全部脚本、strings.json 与目录名称。默认根目录为英文示例；中文在 zh-CN，法文在 fr。三种语言各有完整的操作页面、按钮、提示和模板；书名、视频标识、肌群标识与数据路径在语言之间保持一致。

下载：在 GitHub 源码页选择 Code → Download ZIP，解压后进入 sample。阅读、剧集、地点、学习、运动和豆瓣页面需要 Dataview 并开启 JavaScript Queries；日记来源模板需要 Templater；任务示例需要核心日记。媒体采集本身无需这些插件，也无需 API Key。

Copy the entire **Capture Sample** folder to your Obsidian vault root and open **Capture Sample/Start.md** to select a language. Keep scripts, strings.json and folder names. The root pages and templates default to English; Chinese is in zh-CN and French in fr. All three languages include complete pages, controls, messages and templates. Stable record identifiers and paths are shared across languages.

Download the repository with Code → Download ZIP, then open sample. Interactive trackers require Dataview with JavaScript Queries enabled; Daily source templates use Templater and task logging uses core Daily notes. Media capture itself needs none of these extra plugins or credentials.
