在 **设置 → Media Capture → 功能** 中按需开启模块即可。内置使用指南的“各功能用法”会说明每个模块的准备、操作与结果，设置页则专注于开关与参数配置。

> [!NOTE]
> 关闭模块会保留其配置与历史记录，仅停止对应的记录操作。

## 模块总览

| 模块 | 操作入口 | 准备事项 |
| --- | --- | --- |
| **媒体采集** | 侧栏图标或 **采集媒体** 命令 | 分享链接（无需服务凭证） |
| **任务完成记录** | 勾选普通 Markdown 任务 | 核心**日记**设置与任务记录标题 |
| **剧集记录** | 配套剧集页面 | TMDB API Read Access Token |
| **阅读记录** | 配套阅读页面 | 书名与页码（无需服务凭证） |
| **地点记录** | 配套地点页面 | 高德 Web 服务 Key |
| **学习同步** | 配套同步按钮 | 墨墨开放接口 Token |
| **运动记录** | 配套运动页面 | 视频标识与肌群选项（无需服务凭证） |
| **豆瓣同步** | 配套收藏同步按钮 | 已安装并登录 Douban 插件 |
| **日记信息** | 使用配套模板新建日记 | 选择所需来源并填写对应凭证 |

## 配套页面说明

Media Capture 负责提供记录与写入能力，笔记库负责提供交互页面与展示布局。

> [!IMPORTANT]
> 仅开启模块开关或填写 Token **不会**自动生成书架、地图或日记模板。可直接复制 [示例笔记库](Sample-vault-zh-CN.md) 提供的最小页面，无需自己编写脚本。

### 各模块行为细节

- **剧集记录：** 勾选某集会自动补齐截至该集的未看集数；取消勾选仅影响当前单集。
- **阅读记录：** 按天独立保存每日阅读页码范围。
- **学习同步：** 按页面时区仅处理当天数据（示例库默认使用 `Asia/Shanghai`）。

## 日记信息来源

定位、天气、月相、问候语与诗词均可独立开启，默认均为 **不使用**：

- **月相免凭证：** 直接使用 `wttr.in`，无需填写任何密钥。
- **失败优雅回退：** 已关闭或请求失败的来源不返回内容，由模板回退至默认值。
- **不改写历史日记：** 开启日记来源不会重写已存在的旧日记。
