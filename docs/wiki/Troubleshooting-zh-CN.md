## 常见问题速查

| 现象 | 检查方法 |
| --- | --- |
| **示例页没有交互按钮** | 安装并启用 **Dataview**，开启 **Enable JavaScript Queries**，切换到**阅读视图**，并确保 `Capture Sample/scripts` 目录完整。 |
| **页面提示开启模块** | 在 **设置 → Media Capture → 功能** 中开启对应模块，然后重新打开页面。 |
| **找不到对应凭证输入框** | 先开启所属功能模块，或在日记信息中选择对应来源。 |
| **已填 Token 仍请求失败** | 核对 Token 类型（如 TMDB 需填 `API Read Access Token`）与账号权限；保存输入框不会自动测试连通性。 |
| **获取不到媒体信息** | 确认粘贴的是单集链接（Apple Podcasts 需含 `i` 参数）或完整视频地址，可重试或手动填写标题。 |
| **已保存但缺少封面** | 记录本身依然有效，可稍后在 **维护** 中执行补图。 |
| **找不到刚保存的记录** | 查看采集窗口的目标预览与入门指南；播客与视频清单分别保存（`Podcasts.md` 与 `Videos.md`）。 |
| **没有生成任务日志** | 检查核心**日记**配置、开启**任务完成记录**、核对目标标题，并勾选一条新的普通 Markdown 任务。 |
| **没有出现日记来源内容** | 选择来源并填写凭证后，使用配套的 **Templater** 模板新建一篇空白日记。 |
| **旧笔记没有随模板更新** | 模板仅作用于新建笔记；已有采集记录请在 **维护** 中预览后再批量刷新。 |
| **JSON 或同步冲突报错** | 按报错中的文件路径检查损坏的 JSON 或多端同步冲突，修复后重新加载 Obsidian 再试。 |

## 注意事项

> [!WARNING]
> - **学习同步**按页面时区仅处理**当天**数据，无法用于补写历史日期词数。
> - **豆瓣登录失效**时，请前往 Douban 插件重新登录。
> - **受管同步区：** 请将手写笔记放在受管同步区域之外，避免被覆盖。

> [!TIP]
> 在对已有文件应用模板刷新前，请先核对预览与选中文件列表；刷新操作会自动生成备份。第三方服务返回的报错信息可能会保留其原语言。

## 反馈问题

在 [GitHub Issues](https://github.com/Ch1llNoodle/obsidian-media-capture/issues) 提交反馈时，请附上：

- **Obsidian 版本** 与 **Media Capture 版本**
- 运行平台（**桌面端** / **移动端**）
- 具体操作步骤与可见报错信息

> [!CAUTION]
> 分享日志或截图前，请务必移除 API Key、Token、登录 Cookie 及私有笔记内容。
