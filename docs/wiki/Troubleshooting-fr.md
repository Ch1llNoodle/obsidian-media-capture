### Dépannage

[English](Troubleshooting.md) · [简体中文](Troubleshooting-zh-CN.md) · [Français](Troubleshooting-fr.md)

| Symptôme | Vérification |
| --- | --- |
| Aucun bouton exemple | Activez Dataview et les requêtes JavaScript, utilisez le mode Lecture et gardez tout le dossier scripts |
| Module demandé | Activez-le dans Fonctions puis rouvrez la page |
| Champ d’identifiant absent | Activez sa fonction ou sélectionnez sa source quotidienne |
| Jeton rempli mais échec | Vérifiez son type et ses droits ; le champ ne teste pas la connexion |
| Informations média absentes | Vérifiez le lien d’épisode/vidéo complète, réessayez ou saisissez le titre |
| Enregistré sans couverture | Les données sont valides ; réparez les couvertures dans Maintenance plus tard |
| Note introuvable | Consultez la destination du formulaire et Bien démarrer ; podcasts et vidéos sont séparés |
| Tâche non consignée | Configurez les notes quotidiennes, activez les tâches, vérifiez le titre puis terminez une nouvelle tâche Markdown |
| Sources quotidiennes absentes | Choisissez les sources, renseignez leurs identifiants et insérez le modèle dans une note vide |
| Anciennes notes inchangées | Les modèles concernent les nouvelles notes ; utilisez la prévisualisation Maintenance pour les enregistrements existants |
| Erreur JSON ou conflit | Vérifiez le fichier indiqué, corrigez les données ou la synchronisation puis rechargez |

Les études concernent uniquement le jour du fuseau choisi. Une connexion Douban expirée doit être renouvelée dans le plugin Douban.

Placez vos notes personnelles hors des zones gérées. Avant d’appliquer un modèle, vérifiez prévisualisation et fichiers sélectionnés ; l’opération crée une sauvegarde. Les erreurs d’un service peuvent garder sa langue.

Pour signaler un problème, indiquez versions d’Obsidian et du plugin, plateforme, action et erreur visible. Retirez clés, cookies et données privées.
