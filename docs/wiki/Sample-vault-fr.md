### Coffre exemple

[English](Sample-vault.md) · [简体中文](Sample-vault-zh-CN.md) · [Français](Sample-vault-fr.md)

#### Copier les exemples

1. Ouvrez le [dépôt](https://github.com/Ch1llNoodle/obsidian-media-capture), choisissez Code → Download ZIP, extrayez-le puis ouvrez sample.
2. Copiez tout Capture Sample à la racine du coffre, en conservant son nom, scripts/demo.js et scripts/strings.json.
3. Ouvrez Capture Sample/Start.md et choisissez Français, English ou 简体中文. Chaque langue propose instructions, contrôles, messages et modèles.
4. Activez les modules indiqués et renseignez uniquement leurs identifiants.

#### Dépendances

La capture nécessite seulement Capture ; les tâches nécessitent aussi les notes quotidiennes principales. Lecture, séries, lieux, études, sport et Douban interactifs utilisent Dataview avec Enable JavaScript Queries activé. Ouvrez les pages en mode Lecture. Les modèles de sources quotidiennes utilisent Templater.

#### Essai hors ligne

Ouvrez Lecture, saisissez livre et date, chargez la progression puis enregistrez les pages. Rechargez le même livre pour vérifier. Dans Sport, indiquez une vidéo, choisissez les muscles, enregistrez puis rechargez. Aucun de ces deux exemples ne nécessite une clé.

Séries permet recherche, choix de saison et cases à cocher. Lieux enregistre des visites. Études enregistre les mots du jour. Douban concerne seulement les livres. La page quotidienne explique l’insertion du modèle Templater dans une note datée vide.

#### Données et langues

Les JSON sont dans Capture Sample/data, les notes quotidiennes dans daily, les lieux dans places et les couvertures dans image. Médias et tâches suivent vos réglages existants. Les dates utilisent Asia/Shanghai.

Changer de langue modifie contrôles, instructions et modèles. Les identifiants stables de livre, vidéo et muscle sont partagés, permettant de recharger les mêmes choix dans une autre langue. Les titres et la météo des services ne sont pas traduits automatiquement, ni vos propres noms et données.

Ouvrir une page lit seulement les données locales, sans importer de réglages, créer des fichiers ou contacter des services. Les actions d’enregistrement, recherche, synchronisation et insertion de modèle déclenchent les opérations correspondantes.
