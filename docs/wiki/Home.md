**Media Capture** saves podcast and video share links as ordinary Markdown notes in Obsidian.

> [!TIP]
> Start with a single media record — **no API key, AI service, Dataview, or Templater** is required for the core capture workflow.

## Quick start

1. Install and enable **Media Capture**.
2. Open **Settings → Media Capture → Features** (click the help icon beside the title anytime for in-app guidance).
3. Run **Capture media**, paste a podcast episode or full video link, fetch its metadata, and select **Save and open**.

By default, podcasts are saved to `Podcasts.md` and videos to `Videos.md`. The capture form always previews your actual configured destinations before saving.

## How modules work

> [!NOTE]
> **Media capture** and **Task completion log** work directly out of the box. Other tracking modules (series, reading, places, study, exercise, Douban sync, and Daily sources) require companion pages in your vault — enabling a switch alone does not generate those pages. Use the [Sample vault](Sample-vault.md) to copy ready-made companion pages.
