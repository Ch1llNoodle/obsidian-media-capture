**Media Capture** 可将播客与视频分享链接保存为 Obsidian 中的普通 Markdown 笔记。

> [!TIP]
> 建议先完成第一条采集——核心采集流程**无需 API Key、AI 服务、Dataview 或 Templater**。

## 快速开始

1. 安装并启用 **Media Capture**。
2. 打开 **设置 → Media Capture → 功能**（需要指引时随时点击标题旁的帮助图标）。
3. 运行 **采集媒体**，粘贴播客单集或完整视频链接，获取信息后选择 **保存并打开**。

默认播客写入 `Podcasts.md`，视频写入 `Videos.md`。采集窗口下方会实时预览当前配置的真实保存位置。

## 模块与配套页面

> [!NOTE]
> **媒体采集**与**任务完成记录**开箱即用，自带直接入口。其他追踪模块（剧集、阅读、地点、学习、运动、豆瓣同步、日记信息）需要笔记库中的配套页面——只开启模块开关不会自动生成页面。可直接复制 [示例笔记库](Sample-vault-zh-CN.md) 中现成的配套页面。
